
# My GitHub Practice Project

## About
This is my first Dockerized Python web application.
I am using this project to practice Git, GitHub, and Docker.

## Technologies Used
- Python
- Flask
- Docker
- Git
- GitHub

## How to Run

### Build the Docker image
```bash
docker build -t github-practice .
```

### Run the container
```bash
docker run -d -p 5000:5000 --name github-practice-app github-practice
```

### Open the website
Visit http://localhost:5000 in your browser.

## Learning Goals
- Create and manage a Git repository.
- Practice commits and branches.
- Push changes to GitHub.
- Learn pull requests and merging.
- Build and run a Docker container.
